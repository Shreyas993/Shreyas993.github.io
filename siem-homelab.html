Project Overview

This project demonstrates the implementation of a Security Information and Event Management (SIEM) homelab using Wazuh, Sysmon, Windows 11, and Kali Linux.

Multiple attack simulations were executed to generate endpoint telemetry, validate detections, investigate alerts, and conduct threat hunting activities through the Wazuh Dashboard.

Detection Scenarios

PowerShell Execution

Validated PowerShell monitoring through Sysmon and Wazuh telemetry collection.

Encoded PowerShell

Simulated suspicious command execution using Base64 encoded PowerShell payloads.

Account Discovery

Investigated user enumeration activity mapped to MITRE ATT&CK T1087.

Account Manipulation

Analysed account modification activity mapped to ATT&CK T1098.

Agent Disconnection

Verified monitoring and alerting for agent availability events.

PowerShell Download

Detected file download activity mapped to ATT&CK T1105.
